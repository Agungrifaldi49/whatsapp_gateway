Alur Kerja Efisien

Bagaimana Gateway Bekerja Menghubungkan Sistem Anda

Hanya membutuhkan 4 langkah sederhana dari pemicu event sistem hingga pesan masuk di ponsel pelanggan.

1

Pemicu Event di Sistem Anda

Terjadi transaksi baru di web Anda, pengguna meminta kode OTP, atau admin menjadwalkan broadcast promosi.

2

Panggil HTTP Request API

Sistem Anda mengirimkan nomor tujuan dan isi pesan melalui request HTTP POST JSON sederhana yang diproteksi API Key.

3

Smart Anti-Ban Engine

Gateway memvalidasi format nomor dan menerapkan jeda cerdas (*jitter delay*) agar nomor pengirim aman dan terpercaya.

4

Pesan Diterima Seketika

Pelanggan menerima pesan resmi di WhatsApp dengan tingkat keterbacaan tertinggi, dan status dicatat otomatis di MySQL.

Nilai Lebih

Mengapa Memilih Solusi WhatsApp Gateway Ini?

Solusi mandiri yang memberi Anda kendali penuh atas komunikasi bisnis Anda.

Tanpa Biaya Template Meta

Bebas kirim pesan tanpa persetujuan template (*template approval*) yang memakan waktu dan tanpa tagihan mahal per percakapan.

Privasi & Database Mandiri

Seluruh riwayat log pesan, nomor kontak pelanggan, dan konfigurasi tersimpan 100% aman di server lokal/cloud Anda sendiri.

Dokumentasi Ramah Pengembang

Integrasikan ke Aplikasi Anda dalam Hitungan Menit

Dukung bahasa pemrograman populer dengan endpoint REST API standar yang mudah dipahami.

<?php
/**
 * Contoh Pengiriman Pesan WhatsApp dari PHP
 * Cocok untuk notifikasi order, OTP, tiket, atau konfirmasi akun
 */
function kirimWhatsApp($nomorPenerima, $isiPesan) {
    $endpoint = 'http://localhost:3000/api/send-message';
    $payload  = json_encode([
        'phone'   => $nomorPenerima,
        'message' => $isiPesan
    ]);

    $ch = curl_init($endpoint);
    curl_setopt_array($ch, [
        CURLOPT_POST           => true,
        CURLOPT_POSTFIELDS     => $payload,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER     => [
            'Content-Type: application/json',
            'x-api-key: my_secret_api_key_123'
        ]
    ]);

    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
}

// Contoh pemanggilan saat order masuk / OTP diminta:
$response = kirimWhatsApp('081234567890', "Halo Kak! Pesanan Anda #INV-9821 telah berhasil dikonfirmasi.");
print_r($response);
?>
