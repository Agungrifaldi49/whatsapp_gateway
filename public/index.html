Kelola Sesi Gateway

Jika pesan WhatsApp tidak kunjung terkirim atau sesi mengalami kendala koneksi, Anda dapat memutus sesi saat ini dan menghubungkan ulang dengan memindai kode QR baru.

Peringatan Pemutusan Sesi

Memutuskan sesi akan menghapus kredensial token sesi WhatsApp di server lokal.

Perbaikan Kunci Enkripsi & Anti-Pending (Solusi "Waiting for this message")
E2EE Signal Fix

Jika pesan yang dikirim muncul "Waiting for this message. This may take a while" atau tertahan centang 1 pada nomor penerima tertentu, hal itu disebabkan oleh ketidakcocokan kunci enkripsi sesi (Signal Ratchet out-of-sync). Gunakan alat di bawah ini untuk membersihkan cache kunci yang bermasalah dan menegosiasi ulang Pre-Key baru ke server WhatsApp tanpa harus logout akun Anda.

Panduan Solusi Jika Terjadi Kesalahan (Troubleshooting)

Error Codes & Solutions

Jika pemanggilan API menghasilkan respon gagal atau pesan tidak terkirim, berikut adalah penyebab umum dan solusi perbaikannya:

🛑 401 Unauthorized API Key Salah
Penyebab: Header x-api-key belum diisi, salah ketik, atau token telah di-regenerasi.
Solusi: Salin Token API terbaru dari kotak di atas lalu pastikan header x-api-key: wag_... dikirim pada request.
⚠️ 503 Service Unavailable WhatsApp Terputus
Penyebab: WhatsApp Gateway belum tersambung atau sesi socket terputus.
Solusi: Buka menu Scan QR WhatsApp di dashboard, pastikan statusnya CONNECTED. Jika belum, lakukan scan QR dari aplikasi WhatsApp di HP.
⛔ 403 Forbidden Kuota / Akun Nonaktif
Penyebab: Kuota pesan customer telah habis atau akun customer sedang nonaktif/belum disetujui.
Solusi: Hubungi Administrator untuk menambah kuota pesan atau mengaktifkan status akun Anda.
ℹ️ 400 Bad Request Parameter Tidak Valid
Penyebab: Parameter phone atau message kosong, atau nomor HP salah format.
Solusi: Gunakan nomor berformat Indonesia (contoh: 081234567890 atau 6281234567890) dan pastikan isi pesan tidak kosong.

Konfigurasi Notifikasi Email & SMTP
Belum Dikonfigurasi

Hubungkan akun email (misal: Gmail, cPanel Webmail, atau SMTP Hosting) agar sistem otomatis mengirimkan notifikasi approval dan REST API Key ke inbox email customer.

⚡ Preset Cepat:
Kosongkan jika tidak ingin mengubah sandi yang sudah tersimpan sebelumnya.
💡 Khusus Pengguna Gmail (Wajib Sandi Aplikasi): 🔗 Buka Halaman Sandi Aplikasi Google

Google tidak mengizinkan login menggunakan password email biasa. Anda harus membuat Sandi Aplikasi (16 digit):

  1. Buka myaccount.google.com/apppasswords (Pastikan Verifikasi 2 Langkah akun Gmail Anda sudah aktif).
  2. Beri nama aplikasi, misal: WhatsApp Gateway lalu klik Buat (Create).
  3. Salin 16 karakter sandi yang diberikan Google (contoh: abcd efgh ijkl mnop).
  4. Tempelkan 16 karakter tersebut ke kolom Password / Google App Password di atas.
