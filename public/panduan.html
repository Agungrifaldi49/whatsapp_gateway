01

Pengenalan & Arsitektur Sistem

Gambaran umum alur kerja WhatsApp Gateway Enterprise

WhatsApp Gateway Enterprise adalah sistem penghubung mandiri (self-hosted) yang menjembatani server aplikasi website Anda dengan jaringan resmi WhatsApp menggunakan protokol Multi-Device Baileys modern tanpa bergantung pada vendor pihak ketiga per pesan.

Komponen Inti Gateway:

1

WhatsApp Socket Service

Mengelola koneksi socket enkripsi end-to-end, pairing QR Code, dan persistensi sesi WhatsApp.

2

REST API & Rate Limiter

Menyediakan endpoint JSON cepat yang dilindungi Token API dan limiter anti-spam.

3

Webhook Dispatcher

Meneruskan pesan masuk dan centang laporan pengiriman ke URL server website Anda secara instan.

4

Database MySQL

Menyimpan data otentikasi, kuota customer, histori log keluar, dan inbox pesan masuk secara aman.

02

Panduan Administrator & Pengelola Sistem

Tata cara setup server, penautan nomor WhatsApp gateway pusat, manajemen pengguna, dan pemeliharaan

2.1 Menautkan Nomor WhatsApp Gateway Admin Utama

Untuk mengaktifkan pengiriman pesan pusat (notifikasi sistem, verifikasi akun, dan pesan operasional admin), gateway harus ditautkan ke nomor WhatsApp fisik:

  1. Buka menu "Status & Scan QR WA" pada sidebar panel Admin.
  2. Buka aplikasi WhatsApp di smartphone Anda > Buka menu Perangkat Tertaut (Linked Devices) > Pilih Tautkan Perangkat.
  3. Arahkan kamera smartphone ke QR Code yang tampil di layar browser.
  4. Tunggu 3–5 detik hingga status berubah menjadi CONNECTED. Nomor gateway dan nama pushname Anda akan tampil otomatis.

2.2 Arsitektur Multi-Session & Isolasi Kredensial Baileys

WhatsApp Gateway Enterprise dirancang dengan arsitektur Multi-Tenant Multi-Session terisolasi penuh:

  • Sesi Admin Utama: Disimpan secara permanen pada direktori lokal auth_info_baileys. Sesi ini khusus melayani kebutuhan broadcast admin dan pesan sistem.
  • Sesi Terisolasi Pelanggan (Customer): Setiap akun customer yang disetujui memiliki sub-folder kredensial terpisah (contoh: auth_info_baileys/customer_{id}). Nomor customer tidak akan pernah bentrok, tertukar, ataupun memutus koneksi nomor admin utama.
  • Otomatis Reconnect: Sistem socket Baileys secara otomatis menyambung kembali saat koneksi internet terputus atau server di-restart tanpa perlu scan ulang.

2.3 Manajemen Pelanggan (Approval, Reject, & Suspend)

Setiap pelanggan yang mendaftar via portal pendaftaran masuk dalam antrean moderasi demi keamanan:

  • Menyetujui Customer (Approve): Buka menu "Kelola Customer" > klik tombol Approve. Akun seketika aktif dan email notifikasi persetujuan otomatis dikirimkan ke alamat email terdaftar customer.
  • Penolakan (Reject): Menolak akun yang tidak memenuhi syarat verifikasi pendaftaran.
  • Penangguhan Sementara (Suspend): Tombol Suspend digunakan bila customer terindikasi melanggar aturan broadcast. Kunci API dan akses pengiriman pesan customer seketika diblokir otomatis oleh gateway.

2.4 Pengaturan Batas Kuota Presets (100, 450, 1.000, & Unlimited)

Admin memiliki kendali penuh untuk menentukan jatah kuota pengiriman pesan setiap pelanggan secara fleksibel:

  • Klik tombol Kuota pada baris pelanggan di tabel Kelola Customer.
  • Pilih salah satu preset cepat yang disediakan:
    • 100 Pesan: Cocok untuk paket pengujian atau starter gratis.
    • 450 Pesan: Pilihan ideal paket bulanan basic bagi UMKM / toko online.
    • 1.000 Pesan: Untuk paket bisnis regular dengan volume transaksi menengah.
    • Unlimited (Tanpa Batas / Nilai -1): Memberikan akses pengiriman tanpa batas kuota. Pada dashboard customer akan ditampilkan simbol Sisa Kuota: ∞ (Unlimited).
  • Atau masukkan nominal kuota kustom apa saja sesuai paket langganan pelanggan.

2.5 Konfigurasi Email SMTP Notifikasi Sistem

Gateway dilengkapi modul SMTP otomatis untuk mengirimkan email aktivasi akun baru dan pemulihan kata sandi:

  • Layanan Gmail: Host: smtp.gmail.com | Port: 587 (TLS) | Wajib menggunakan App Password 16 karakter dari konsol Keamanan Google Account (bukan password login biasa).
  • Layanan cPanel / Mail Server: Host: mail.domainanda.com | Port: 465 (SSL) atau 587 (TLS).
  • Pengujian Langsung: Tekan tombol "Kirim Email Test" pada menu Pengaturan SMTP untuk memastikan konfigurasi berjalan lancar tanpa kendala koneksi.

2.6 Monitoring Global, Log Terurut Descending, & Kapasitas Berkas 50MB

Seluruh aktivitas operasional gateway dipantau melalui logging komprehensif:

  • Log Pesan Keluar Global: Seluruh riwayat pesan keluar tersusun secara descending (pesan terbaru berada di baris teratas) dengan pembagian halaman (pagination) 10 data per halaman agar sistem tetap gesit. Dilengkapi filter pencarian real-time.
  • Dukungan Berkas hingga 50MB: Server telah dikonfigurasi dengan limit payload 50mb, memungkinkan pengiriman dokumen e-book, modul belajar, rekaman presentasi, dan file lampiran PDF berukuran besar tanpa kendala HTTP 413 (Entity Too Large).
  • Pesan Masuk (Global Inbox): Administrator dapat meninjau balasan chat dari seluruh nomor secara real-time.
03

Panduan Pelanggan (Customer Guide)

Cara menggunakan portal, scan WhatsApp mandiri, kelola kuota, dan integrasi pengiriman berkas dokumen

3.1 Pendaftaran Akun Mandiri & Verifikasi Email

Langkah mudah memulai menggunakan WhatsApp Gateway untuk kebutuhan bisnis, sekolah, atau instansi Anda:

  1. Buka portal web WhatsApp Gateway dan klik tab "Daftar Akun Baru".
  2. Lengkapi formulir pendaftaran: Nama Lengkap, Username, Alamat Email Aktif, Nomor WhatsApp Pribadi, dan Password yang aman.
  3. Setelah pendaftaran berhasil dikirimkan, sistem akan mendaftarkan akun Anda dalam status menunggu verifikasi (Pending).
  4. Anda akan menerima pemberitahuan resmi via email begitu akun Anda disetujui (Approved) oleh Administrator dan siap digunakan.

3.2 Menautkan Nomor WhatsApp Bisnis Sendiri (Scan QR Mandiri Multi-Session)

Setiap akun pelanggan dilengkapi dengan sesi WhatsApp mandiri yang sepenuhnya terisolasi. Nomor WhatsApp Anda tidak akan pernah bercampur dengan akun pengelola maupun pelanggan lainnya:

  1. Masuk ke akun Customer Anda, lalu klik menu "Status & Scan QR WA" di navigasi samping.
  2. Sistem secara otomatis akan menginisiasi sesi pribadi Anda dan menampilkan QR Code aktif (status: QR READY).
  3. Buka aplikasi WhatsApp di smartphone bisnis Anda > buka menu Perangkat Tertaut (Linked Devices) > pilih Tautkan Perangkat.
  4. Arahkan kamera smartphone Anda ke kode QR yang muncul di layar monitor.
  5. Dalam 3–5 detik, status akan berubah menjadi CONNECTED lengkap dengan rincian nomor WhatsApp bisnis Anda. Seluruh pesan yang dikirim dari akun Anda akan murni memakai nomor Anda sendiri.
🔒
Keamanan Privasi 100%: Chat, kontak, dan kredensial nomor WhatsApp Anda tersimpan secara terisolasi. Pengguna lain tidak dapat melihat atau menggunakan sesi WhatsApp Anda.

3.3 Mengakses Token API Personal & Memantau Kuota

Setiap pelanggan memiliki Token API unik untuk menghubungkan website atau aplikasi internal ke gateway:

  • Masuk ke menu "Token API & Webhook" di dashboard Anda.
  • Klik tombol Salin Token untuk menyalin token ke clipboard. Gunakan tombol Regenerasi sewaktu-waktu jika token Anda perlu diperbarui.
  • Status Kuota Pesan: Pantau sisa kuota pengiriman Anda pada badge navigasi di kanan atas (misalnya: Sisa Kuota: 450 atau simbol tak hingga Sisa Kuota: ∞ (Unlimited) jika Anda memiliki paket tanpa batas).
  • Jika kuota Anda menipis, Anda dapat menghubungi pihak Administrator untuk penambahan kuota baru.

3.4 Mengirim Pesan Tunggal & Lampiran Dokumen / Media (PDF, Excel, Foto)

Anda dapat mengirimkan pesan teks dan berkas dokumen langsung melalui formulir web yang intuitif:

  • Nomor Tujuan: Masukkan nomor WhatsApp tujuan (contoh: 081234567890 atau 6281234567890). Sistem otomatis merapikan format nomor.
  • Pesan Teks & Pratinjau Interaktif: Tuliskan isi pesan. Pratinjau di layar sebelah kanan akan memperlihatkan simulasi balon chat WhatsApp secara real-time persis seperti di ponsel penerima.
  • Lampiran Berkas (File Dokumen / Media): Anda dapat mengunggah file dokumen seperti PDF Jadwal Pelajaran, Brosur Foto (JPG/PNG), Faktur Tagihan, hingga Spreadsheet Excel. Berkas hingga ukuran 50MB didukung secara penuh.
  • Nama Dokumen Kustom: Tentukan nama dokumen yang akan muncul saat file diunduh oleh penerima di WhatsApp (contoh: Jadwal_Pelajaran_Semester_Genap.pdf).

3.5 Broadcast / Pesan Massal (Blast) dengan Jeda Dinamis Anti-Ban

Fitur pengiriman broadcast dirancang khusus dengan proteksi keamanan tingkat tinggi:

  • Daftar Nomor Penerima: Masukkan daftar nomor telepon tujuan pada area teks broadcast (satu nomor per baris). Sistem secara cerdas akan memvalidasi nomor-nomor yang valid.
  • Pesan Serentak / Lampiran Berkas: Anda dapat menyertakan pesan pengumuman bersama berkas lampiran (seperti dokumen PDF jadwal atau pengumuman penting).
  • Jeda Dinamis (2–4 Detik): Gateway secara cerdas menerapkan interval jeda acak antar pengiriman untuk menghindari deteksi spam WhatsApp, menjaga nomor bisnis Anda tetap aman dari risiko pemblokiran.
  • Laporan Pengiriman Berkelanjutan: Hasil pengiriman (berhasil / gagal) ditampilkan secara transparan seketika proses broadcast berjalan.

3.6 Skenario Nyata: Bot WhatsApp Otomatis Jadwal Pelajaran Siswa

Salah satu pemanfaatan paling populer untuk sekolah, bimbingan belajar, atau kampus adalah bot otomatis berkas jadwal:

1

Siswa Mengirim Chat

Siswa atau wali murid mengirim pesan ke nomor WhatsApp Anda dengan kata kunci: jadwal atau #jadwal.

2

Webhook Menangkap Pesan

Sistem gateway meneruskan pesan masuk tersebut ke endpoint website sekolah Anda dalam hitungan milidetik.

3

Bot Mengirimkan PDF

Aplikasi Anda langsung memanggil API Gateway untuk membalas otomatis dengan melampirkan berkas dokumen Jadwal_Pelajaran.pdf.

4

Siswa Menerima Dokumen

Siswa langsung menerima file PDF jadwal resmi di WhatsApp mereka tanpa perlu dilayani manual oleh petugas tata usaha.

3.7 Memantau Pesan Masuk (Inbox Real-Time) & Histori Laporan

  • Inbox Pesan Masuk: Seluruh balasan chat dari pelanggan, siswa, atau klien yang masuk ke nomor Anda tersaji di menu "Pesan Masuk (Inbox)" secara real-time.
  • Penyegaran Cepat: Tombol "Segarkan Inbox" dan "Segarkan Log" memungkinkan Anda mengecek pembaruan status pesan seketika tanpa harus memuat ulang seluruh halaman web.
  • Histori Pengiriman: Anda dapat melihat status keterkiriman (Terkirim, Sampai, Dibaca) dengan nomor urut descending untuk memudahkan pelacakan pesan terakhir.

4.2 POST /api/send-message & POST /api/v1/send-media (Kirim Pesan & Dokumen)

Mengirimkan pesan teks atau dokumen/media (PDF Jadwal Pelajaran, Gambar, Excel, Word) ke nomor WhatsApp tujuan.

Parameter Tipe Wajib? Keterangan
phone string Ya Nomor WhatsApp penerima (contoh: 081234567890 atau 6281234567890)
message string Kondisional Teks pesan atau caption pengantar file (wajib jika tidak melampirkan file/media)
fileBase64 string Opsional Isi file dalam format Base64 (contoh: data:application/pdf;base64,JVBERi0...)
mediaUrl string Opsional Tautan URL file dokumen/gambar publik yang dapat diunduh (contoh: https://sekolah.sch.id/jadwal.pdf)

Webhook Real-Time WhatsApp & Keamanan

Menerima pesan masuk dan status centang dua/biru secara instan di website Anda

5.1 Cara Kerja Webhook

Saat nomor gateway menerima pesan dari pelanggan atau saat pesan terkirim ke HP penerima, Gateway secara otomatis melakukan request HTTP POST ke URL Webhook yang Anda daftarkan di dashboard.

5.2 Verifikasi Signature Keamanan (HMAC-SHA256)

Untuk memastikan request yang masuk ke website Anda benar-benar berasal dari WhatsApp Gateway (dan bukan penyerang), Gateway menyertakan header verifikasi:

  • X-Webhook-Signature: Kode hash HMAC-SHA256 dari payload JSON menggunakan Secret Token Anda.
  • X-Webhook-Secret: Secret Token Anda.
  • X-Webhook-Event: Nama event (misal: message_received, message_delivered, message_read).

5.3 Struktur Payload JSON Event Masuk

JSON Payload: message_received
{
  "event": "message_received",
  "timestamp": "2026-09-13T12:45:00.000Z",
  "data": {
    "msgId": "3EB0998811AA2233",
    "senderPhone": "6281234567890",
    "senderJid": "6281234567890@s.whatsapp.net",
    "senderName": "Budi Santoso",
    "message": "Halo admin, apakah produk ini masih tersedia?",
    "isGroup": false
  }
}

Pusat Contoh Integrasi Siap Pakai

Koleksi kode siap salin untuk berbagai bahasa pemrograman & framework

A. PHP Native (cURL) — Mengirim Pesan WhatsApp

send_wa.php
<?php
function sendWhatsApp($phone, $message) {
    $url = 'http://localhost:3000/api/send-message';
    $apiKey = 'my_secret_api_key_123'; // Ganti dengan Token API Anda

    $payload = json_encode([
        'phone'   => $phone,
        'message' => $message
    ]);

    $ch = curl_init($url);
    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_POST           => true,
        CURLOPT_POSTFIELDS     => $payload,
        CURLOPT_TIMEOUT        => 15,
        CURLOPT_HTTPHEADER     => [
            'Content-Type: application/json',
            'x-api-key: ' . $apiKey
        ]
    ]);

    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
}

// Contoh Penggunaan:
$kirim = sendWhatsApp('081234567890', "Pesanan #INV-9021 telah berhasil dibayar. Terima kasih!");
print_r($kirim);
?>

B. PHP Webhook Handler (`webhook.php`) — Menerima Chat & Event

webhook.php
<?php
header('Content-Type: application/json');

// 1. Tangkap Payload dari Gateway
$rawPayload = file_get_contents('php://input');
$payload = json_decode($rawPayload, true);

if (!$payload || !isset($payload['event'])) {
    http_response_code(400);
    echo json_encode(['status' => false, 'message' => 'Invalid payload']);
    exit;
}

$event = $payload['event'];
$data  = $payload['data'];

// 2. Verifikasi Signature Keamanan HMAC-SHA256 (Opsional)
$secret = 'whsec_secret_anda'; // Samakan dengan Secret di dashboard
$signature = $_SERVER['HTTP_X_WEBHOOK_SIGNATURE'] ?? '';

if ($secret && $signature) {
    if (!hash_equals(hash_hmac('sha256', $rawPayload, $secret), $signature)) {
        http_response_code(403);
        echo json_encode(['status' => false, 'message' => 'Invalid HMAC Signature']);
        exit;
    }
}

// 3. Proses Event Berdasarkan Tipe
if ($event === 'message_received') {
    $sender = $data['senderPhone'];
    $pesan  = $data['message'];
    
    // Contoh: Simpan ke database toko Anda atau buat bot balasan otomatis
    file_put_contents('inbox_log.txt', "Dari $sender: $pesan\n", FILE_APPEND);
} elseif ($event === 'message_delivered') {
    // Pesan telah sampai di HP pelanggan (centang dua abu-abu)
} elseif ($event === 'message_read') {
    // Pesan telah dibuka/dibaca pelanggan (centang dua biru)
}

// 4. Berikan respon HTTP 200 OK
echo json_encode(['status' => true, 'event' => $event]);
?>

C. Laravel (Service Class)

app/Services/WhatsAppGatewayService.php
<?php
namespace App\Services;

use Illuminate\Support\Facades\Http;

class WhatsAppGatewayService
{
    protected $url;
    protected $token;

    public function __construct()
    {
        $this->url = env('WA_GATEWAY_URL', 'http://localhost:3000');
        $this->token = env('WA_GATEWAY_TOKEN', 'my_secret_api_key_123');
    }

    public function sendMessage(string $phone, string $message): array
    {
        $response = Http::withHeaders([
            'x-api-key'    => $this->token,
            'Content-Type' => 'application/json',
        ])->post("{$this->url}/api/send-message", [
            'phone'   => $phone,
            'message' => $message,
        ]);

        return $response->json();
    }
}

D. Kasus Nyata: Bot WhatsApp Pengiriman Jadwal Pelajaran (File PDF) Otomatis

Contoh skrip PHP pada server aplikasi website Anda yang menangkap webhook saat siswa atau wali murid mengirim pesan #jadwal atau jadwal, lalu otomatis membalas dengan mengirimkan dokumen PDF jadwal resmi:

bot_jadwal_sekolah.php
<?php
// 1. Tangkap kiriman webhook dari WhatsApp Gateway
$raw = file_get_contents('php://input');
$payload = json_decode($raw, true);

if (isset($payload['event']) && $payload['event'] === 'message_received') {
    $senderPhone = $payload['data']['senderPhone'];
    $incomingMsg = strtolower(trim($payload['data']['message'] ?? ''));

    // 2. Deteksi apakah pesan mengandung kata kunci 'jadwal'
    if (strpos($incomingMsg, 'jadwal') !== false) {
        $gatewayUrl = 'http://localhost:3000/api/send-message';
        $apiKey     = 'YOUR_CUSTOMER_API_TOKEN';

        // 3. Siapkan payload dokumen PDF jadwal pelajaran
        $postData = json_encode([
            'phone'    => $senderPhone,
            'message'  => "Halo! Berikut terlampir Jadwal Pelajaran Resmi Semester Baru.\nSilakan simpan berkas PDF berikut.",
            'fileName' => 'Jadwal_Pelajaran_Resmi_2026.pdf',
            'mediaUrl' => 'https://sekolah.sch.id/files/Jadwal_Pelajaran_2026.pdf'
        ]);

        $ch = curl_init($gatewayUrl);
        curl_setopt_array($ch, [
            CURLOPT_POST           => true,
            CURLOPT_POSTFIELDS     => $postData,
            CURLOPT_RETURNTRANSFER => true,
            CURLOPT_HTTPHEADER     => [
                'Content-Type: application/json',
                'x-api-key: ' . $apiKey
            ]
        ]);
        curl_exec($ch);
        curl_close($ch);
    }
}

// 4. Balas status 200 OK ke Gateway
echo json_encode(['status' => true]);
?>

Troubleshooting, FAQ, & Best Practice

Solusi kendala teknis yang sering ditemui dan tips anti-banned
Kendala / Pesan Error Kemungkinan Penyebab Langkah Solusi
401 Unauthorized Token API tidak dikirim atau sudah kedaluwarsa Periksa header x-api-key atau Authorization: Bearer <token> di website Anda.
403 Kuota Pesan Habis Kuota pengiriman akun customer telah mencapai batas maksimum Hubungi Admin untuk upgrade kuota atau top-up pesan melalui dashboard.
WhatsApp Belum Terhubung Nomor WhatsApp belum dipindai QR atau terlogout Buka menu Status & Scan QR di dashboard dan tautkan ulang perangkat Anda.
Pesan Tidak Sampai ke Penerima Nomor tujuan tidak terdaftar di WhatsApp atau format salah Gunakan format nomor internasional Indonesia diawali 08 atau 628 (contoh: 081234567890).

💡 5 Tips Penting Mencegah Pemblokiran Nomor WhatsApp (Anti-Banned):

  1. Gunakan Nomor WhatsApp yang Sudah Berumur: Hindari menggunakan kartu perdana yang baru diaktifkan hari ini untuk mengirim ribuan pesan blast.
  2. Gunakan Jeda Otomatis: Jangan hilangkan fitur delay 2–4 detik per pesan pada fitur broadcast.
  3. Sesuaikan Konten Pesan: Gunakan variabel nama penerima agar pesan bervariasi dan tidak dianggap spam massal oleh filter WhatsApp.
  4. Pastikan Pelanggan Mengenal Anda: Kirimkan notifikasi transaksi (seperti resi, faktur, invoice) yang memang dinantikan oleh pelanggan.
  5. Sediakan Opsi Berhenti Langganan: Tambahkan teks sopan di akhir pesan jika mengirim pesan promosi.
